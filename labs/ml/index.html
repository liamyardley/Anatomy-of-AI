Machine Learning Lab

Machine learning means showing a computer lots of examples and letting it work out the rule for itself. Here the examples are red and blue points, and the rule to find is where red ends and blue begins.

Pick a dataset, choose a model's settings, press Train and watch it learn. Then change something and train again: the quickest way to understand a setting is to see what it does.

This lab needs to be opened through a web server. If you are running it from a folder on your computer, open a terminal in the project folder, run python -m http.server, then visit http://localhost:8000/labs/ml/.

What is a seed?

The datasets are random, but a computer's randomness starts from a number called a seed. The same seed always produces exactly the same dataset, so a whole class can type in the same seed and see the same points. Regenerate picks a new seed for you.

Reading the plot

Colours, shapes and held-back points

Each point has two measurements, called features: x1 (left to right) and x2 (bottom to top). Each point also has a class, the answer we want a model to predict: red or blue.

  • Red points are circles, blue points are triangles, so you never have to rely on colour alone.
  • Solid points are training points. These are the examples a model learns from.
  • Hollow grey points are test points. They are held back and never shown to the model, so they reveal how well it copes with data it has not seen. They are drawn without colour because, as far as the model is concerned, their class is unknown; the shape still records the true answer (circle for red, triangle for blue) so predictions can be checked against it. This lab uses a 70/30 train/test split: 70% of the points are used for training and 30% are held back for testing.
  • Shading is the model's opinion. Once a model is trained, the plot is shaded red where it thinks a point would be red and blue where it thinks blue. Strong colour means it is confident; pale means it is unsure. The dark line is the boundary, where its prediction switches.
