How a model finds its numbers

In the Machine Learning Lab you pressed Train and a model found its own numbers. This lab slows that moment down to show what is happening.

It starts with the smallest case there is: a model with one number to find. Try to find it yourself first, then watch the method a computer uses.

This lab needs to be opened through a web server. If you are running it from a folder on your computer, open a terminal in the project folder, run python -m http.server, then visit http://localhost:8000/labs/training/.
